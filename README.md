# Gusto Payroll — HR & Payroll Landing Page (Front-End Implementation)

A fully responsive HR & Payroll business landing page, built as a **front-end implementation** using **HTML, CSS, and Bootstrap 5**. This project recreates a multi-section corporate layout and demonstrates practical skills in building responsive designs, interactive components, and clean layouts.

## 🚀 Key Features
- **Fully Responsive Layout** — Optimized for mobile, tablet, and desktop.
- **Modern Navigation Bar** — Dropdown menus for seamless navigation.
- **Off-Canvas Mobile Sidebar** — Mobile-friendly sidebar menu.
- **Hero Section** — Call-to-action buttons and prominent headings.
- **Review/Awards Slider** — Smooth marquee-style carousel.
- **Product Feature Accordions** — Expandable sections for features.
- **Multiple Business Sections** — Cards, grids, and pricing blocks.
- **Professional Footer** — Accordion layout for mobile devices.
- **Clean Design** — Thoughtful typography and color palette.

## 📂 Technologies Used
- HTML5 & CSS3  
- Bootstrap 5  
- Font Awesome Icons  
- Responsive Design Techniques
